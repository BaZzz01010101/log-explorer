# Inspector defaults and proportional event overview

Newly opened event viewers show the right inspector immediately and select the first available event. Its initial width is 30% of the event body, including the space shared by the list and inspector. The default follows parent resizing until the user resizes it manually. Existing pointer/keyboard resizing, cancellation and width clamping remain available; hiding and reopening retains the current selection and chosen width. The button directly beside Export shows or hides the inspector and indicates its current state.

The overview maps complete event intervals to track pixels, using measured/estimated virtual row heights and the actual content extent. Adjacent pixels with the same colors merge into one band. Three consecutive equally tall errors therefore form a band about three times the height of one error, rather than three separated midpoint dots. Genuine uncolored intervals remain gaps. Very dense rows share pixels: higher severity wins, and up to four distinct highlight colors share a pixel. Rendering is bounded by track resolution.

Clicking within a merged band selects the matching event at that position using its measured interval, including when row heights vary. The native scrollbar thumb remains independently draggable. Severity stays on the left and highlights on the right of the compact 20-pixel track.

Two defects affected right-lane visibility. The inspector resize handle previously extended three pixels across the five-pixel highlight lane; it now stays inside the inspector, and the overview has an explicit stacking level. Quick matching previously searched only raw messages, while the viewer can highlight decoded JSON and formatted column values. Overview matching now reuses those bounded display fields and column/timezone settings in the guarded worker. Regex timeout, batching, cancellation and offline isolation remain intact.

Regression tests reproduce the midpoint gaps, missing decoded/formatted matches, resize-handle obstruction and old inspector defaults. Hidden desktop tests check the 30% ratio, toggle location/state, new tabs, resize retention, contiguous band geometry and native captured pixels, navigation within each third of a three-event band, and full-lane hit testing in both themes. Reports and captures are under `.tmp`; final artifact and verification details are in [Feature status](feature-status.md).
