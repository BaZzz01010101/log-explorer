# Explorer selectors and quick highlighting

Version 0.1.8 replaces the 0.1.7 account/region hierarchy with separate Profile and Region dropdowns above Explorer. The tree contains only log groups and their log streams. Loaded-stream filtering is removed. Group-name substring search, automatic continuation, keyboard navigation, preview tabs, favorites, resource details and source dragging remain available.

Only the selected region loads and renders its group list. Caches remain isolated by connection/search and can be reused when switching back. Changing regions or search text resets list position and selections. Identical resource names in different regions retain their connection identity. Profile selection prefers the current region when it exists in the new profile, otherwise its first configured region. Explicit dropdown choices persist independently of open views.

Connections settings now shows added profiles, each with only its added region rows. Add profile opens the known-profile choice; each card has a searchable Add region choice that matches region codes and locations. Unselected known profiles and regions appear only in these pickers. Removing a profile hides it but retains its region selections. Removing a region disables that connection; re-adding it reuses its ID. Open tabs retain their sources and view state. Existing configured profiles migrate naturally, and an added profile can be saved before it has any regions. Manual connection editing remains under Advanced connection settings. Profile discovery remains unavailable until an explicitly authorized packaged AWS session.

Each viewer has a clearable Highlight text field beside loaded-event search. It matches literal text without changing the loaded-event filter or running another service query. It applies in JSON, Table, Hybrid and the docked inspector. Text is saved per view, including an explicitly cleared value; new views start clear. Older views without this field retain the legacy global text until edited. The quick field is bounded to the renderer's 200-character literal limit. Advanced regex highlight profiles remain under Settings → Highlights.

Focused tests cover tree levels and keyboard traversal, selected-region isolation, stale cursors, add/remove/re-add settings, custom regions and object-like names, and highlight persistence. Hidden desktop checks exercise the real dropdowns and buttons, natural restart, literal marks in all three modes and inspector content, stable row counts and no query updates while editing highlights, plus independent text in a newly opened view. Captures are inspected while windows stay hidden.

The complete packaged regression result and artifact hashes are recorded in [feature status](feature-status.md). Evidence remains under `.tmp`. Tests use isolated storage with immutable AWS denial; real AWS and user workspace data are not accessed. The Windows installer is unsigned and is not installed by development tooling. The normal launch folder is updated only when the current app is closed; a staged update can wait for it without closing or focusing a window.
