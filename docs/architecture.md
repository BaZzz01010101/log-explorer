# AWS Log Explorer

## Intent and constraints

A local, keyboard-friendly desktop workspace for everyday CloudWatch investigation. Resource navigation, queries, live monitoring and structured event inspection share one actual data path. Offline fixtures are explicitly labeled; they never imply verified AWS behavior. Development, tests and unpackaged builds must not read AWS configuration or connect to AWS. No backend infrastructure is needed.

## Architecture

Electron hosts a sandboxed React renderer. Only the main process imports the official AWS SDK, resolves profiles, accesses files or starts network operations. A narrow typed preload bridge validates all incoming requests. The application initially starts offline. Packaged builds remember deliberate AWS enable/disable choices in a separate access-settings.json file; development and verification ignore that preference and cannot enable AWS. Workspace data never restores authorization. Enabling refreshes resource caches and retries AWS view queries.

Electron is selected over Tauri for the mature Node credential-provider ecosystem and Windows integration. Mantine supplies accessible dialogs, menus and forms. TanStack Table and Virtual handle columns and bounded rendering. TypeScript contracts isolate service implementations from workspace and visualization logic.

## Modules and behavior

- `src/shared`: serializable contracts, bounded JSON parsing/flattening and the bounded binary split-layout model.
- `src/main`: gated CloudWatch adapter, offline adapter, cancellable jobs, bounded concurrency, atomic persistence, export dialogs and desktop lifecycle.
- `src/renderer`: independent tab configurations, named colored groups, bounded multi-pane workspace, resource sidebar, query toolbar, reusable queries, preferences and event viewer.
- `tests`: isolated unit/integration tests and Electron smoke coverage. A setup hook denies external network and redirects credential paths to nonexistent fixture locations.

Event fetching uses FilterLogEvents with explicit continuation and automatically follows bounded runs of empty pages that still have a token. Reaching that scan budget preserves a user-accessible continuation. Stream selection is passed to AWS. Insights uses StartQuery, bounded polling and StopQuery on cancellation. Aggregation results are retained as structured rows. Live Tail uses the service stream and surfaces sampling. Events can combine configured connections/regions in one view; Insights and Live Tail require one connection/region. Separate panes retain independent source configurations. Cancellation and generation IDs prevent stale responses from replacing newer results. View buffers have a configurable upper bound and report eviction/truncation. Metadata is lazily fetched and cached by connection and search text. Group discovery uses AWS's case-sensitive substring search and hydrates the exact matching names to retain complete group metadata.

Resource clicks open transient preview tabs. Another resource replaces an eligible preview in the target pane while previews displayed elsewhere remain intact. Double-clicking a resource or preview label keeps that tab permanently. Changes to its query, filter pattern, source, connection or query kind also promote the preview so that a later resource click cannot discard the edited query. Date and visualization changes alone leave it transient. Tabs can be moved between panes without duplicating a displayed tab; splitting a displayed view creates an independent configuration when a second instance is required.

Explorer selects one configured profile and region with dropdowns and projects only its groups and streams into a virtual tree. Group/stream keys include connection IDs; legacy duplicate endpoints prefer the selected ID while retaining favorites for all configured IDs. Per-region caches and request generations isolate pages, stale search results and refreshed streams. Switching regions resets list position and group selection. Connections settings shows added profiles and regions, using searchable known-name pickers to add more. Removal retains connection IDs and tab state; it never changes AWS authorization. Region metadata is a static catalog from the installed SDK. Local profile discovery remains behind the existing main-process authorization gate. Quick literal highlighting is saved in each view and rendered beside local event search; older views fall back to the legacy preference until edited.

The top-level strip contains normal and combined entries. Flat `Workspace.tabs` retain log-view configurations and query IDs; `splitTabs` own combined memberships and binary layouts, `tabOrder` records strip order, and `activeTabId` selects the visible entry. `panes`, `layout` and `activePaneId` project only that entry. Activating a normal entry always restores one full pane. `activeConnectionId` persists the explorer selection independently, including when no views remain. Member views belong to one combined entry and do not also appear in the strip.

Each combined layout has at most 100 unique pane leaves within the workspace's 100-view budget, with proportions bounded to 20–80%. Iterative validation caps trees at 199 nodes before normalization, including cyclic input. Whole combined-tab drops graft its subtree into the destination and preserve member query IDs. Selected resource batches use the same projection and grafting mechanism; the preview covers their full occupied area, with one pane per group or explicitly selected stream. Context-created views use the same group presets as regular opening and dragging. Header dragging reuses whole-tab placement: centers swap member views, edges remove the source leaf before insertion, and tab-strip drops detach at the chosen position. A one-member combined entry dissolves into a normal tab. Divider movement renders locally while dragging and persists on release. Main-process IPC validation rejects invalid membership, ordering and projection references. File/import validation first checks view data, then performs bounded restoration and strictly validates its output, so damaged split metadata can dissolve without replacing current valid views with an older backup. Version-0/version-1 global split sessions migrate to a combined entry. ID allocation reserves open views, combined entries and closed history, including custom IDs accepted in imports.

Explorer regex discovery scans unfiltered group pages and matches names in a terminable worker. Scope generations reject late pages; leaving an unfinished scan evicts its incomplete cache so returning restarts discovery. Profile and region dropdowns accept configured choices only. Group/stream selection supports toggles and ranges, normalized batch payloads, cursor-positioned context actions and captured-pointer dragging. Event-row selection is separate from the current inspector row; copying walks displayed filtered/sorted rows, including virtualized rows. Explicit list select-all clears stale native text selection, while editable controls and inspector text keep native copying.

AWS revocation is persisted before waiting for shutdown. Ordinary operations immediately lose authorization; cancellation of an already-started Insights query can send only StopQuery through its cached transport with a bounded timeout, without constructing another client. Shutdown failures still surface explicitly.

Normal `customTitle` labels are separate from base resource labels and reset when closed. Combined custom titles survive layout changes until exit/close; exiting restores adjacent normal members. Duplication inserts an independent normal or combined entry directly after its original. Group, stream and event continuation uses scroll/resize sentinels with stable query generations and per-request page keys; event cursor sessions can retain the same opaque ID across pages. New views start with a clear date range; a Relative/Absolute picker stores canonical instants and exposes adjacent Local/UTC display selection. Bulk message expansion uses per-mode defaults and individual exceptions while retaining virtualization. Direct Table/Hybrid header dragging preserves hidden column slots and pinning sections, has a distance threshold to distinguish sorting, and captures the pointer through scrolling and cancellation.

JSON, table and hybrid modes share stable event IDs. Flattened paths use JSON Pointer to preserve dotted keys and arrays. Expandable inspection is bounded by depth and node count. Search over loaded events is labeled local; filter patterns and Insights are labeled server-side. Export includes only the loaded/filtered selection. Sessions persist configurations, never log payloads or credentials. Corrupt persistence recovers with a backup and a visible warning.

The event overview overlays two bounded color lanes on a 20-pixel native scrollbar. Severity comes from prepared row levels; profile and literal matches use a summary mode of the existing guarded highlight worker, with 100-event input batches and progress/result batching. Quick summaries include bounded decoded values and formatted columns, with timezone/column configuration in the cache key. Visible-row text spans keep their separate priority worker. Filtered/sorted row IDs join summaries to virtualizer measurements; each full row interval paints track pixels, and adjacent matching colors merge into proportional bands. Dense pixels retain higher severity and up to four highlight colors. Navigation within a merged band chooses the matching measured interval before selecting/scrolling. The overview has an explicit stacking level, and the inspector resize handle stays inside its own pane.

Event selection initializes with the inspector open and selects the first arrival. A toolbar toggle beside Export shows/hides it while retaining selection. Inspector width follows 30% of its event-area parent until manually resized; pointer/keyboard width, clamping, cancellation and hide/show retention use the existing local resize state.

## Delivery and verification

Implement small vertical steps: contracts and safety; service and fixtures; secure desktop shell; full workspace; structured viewer; integration and packaging. Validate parsing, pagination, cancellation, AWS gating, persistence, tab/split invariants and the real desktop path with fixtures. Build an unpacked Windows application and installer configuration. Code signing and macOS/Linux artifacts require their respective release environments. No production-readiness claim substitutes for these checks.

Source badges edit persisted view sources directly. An optional source `connectionId` overrides the view default; query snapshots include the referenced connections. Source identity and request generations include every referenced profile/region, so changes cancel retired requests and query automatically. Multi-connection historical events reuse the existing adapters per source with a bounded merge of unread heads and opaque 15-minute continuations; event IDs are namespaced by connection and source context opens the originating region. Continuations are bounded by count/message characters and invalidated after failed/cancelled reads. Live Tail and Insights retain single-connection semantics. Stream pages request descending last-event time and merged caches sort defensively.

Explorer resource drags use captured pointers and the existing projected pane geometry. A source-strip drop adds sources; a pane drop atomically inserts a draft view and creates/extends a combined entry, rejecting full layouts without orphan views. Draft previews never publish query IDs. Hover activation preserves the Explorer connection and restores the original entry on cancellation. Shared drag state reveals the normally hidden single-source control even when a target pane mounts midway through a drag. Generated mixed-view/combined names count individual selected streams and sum across member panes; explicit names retain priority. Pane-header backgrounds have dedicated theme tokens distinct from event statuses.
